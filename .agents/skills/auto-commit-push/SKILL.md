# 自動提交並推送

使用者已授權此專案：只要任務更動檔案，完成該次工作與適當檢查後，直接 commit 並 push，不再詢問確認。以一次完整任務的相關變更為單位提交，不必每次存檔都提交。

- 先查看 Git 狀態與差異，明確加入本次任務新增、修改或刪除的檔案；不要順便提交原本就存在且與本次任務無關的變更。
- 完成適合該次修改的檢查，使用簡潔、描述實際變更的 commit 訊息提交至目前分支。
- 推送至目前分支的 upstream；若沒有 upstream，但已設定 origin，使用 `git push -u origin HEAD`。遵循既有遠端設定，包括多個 push URL。
- 沒有變更時不建立空提交。若本次提交成功但推送失敗，保留提交並回報原因，不要聲稱已推送成功。
- 不使用 force push、不重寫歷史、不刪除其他人的變更；遇到遠端領先或衝突時，保留現況並回報阻礙。
- 完成後簡短回報 commit 識別碼及推送結果。使用者當次明確要求不要提交或推送時，遵循當次指示。
